# Docker Chatroom

用 Python socket 寫的多人聊天室，有圖形化介面。聊天室裡可以按一個按鈕隨機抽一題辯論題，讓大家從辯論中認識彼此。

三個服務（驗證、聊天、資料庫）用 Docker 啟動，client 直接在自己的電腦上執行。

## 功能

| 功能 | 說明 |
|------|------|
| 註冊 / 登入 | 帳號密碼存在 MySQL，擋重複帳號 |
| 即時聊天 | 訊息立刻送到同聊天室的所有人 |
| 歷史訊息 | 進聊天室自動載入先前的對話；也可以查單一帳號說過的話 |
| 抽辯論題 | 從 100 題題庫隨機抽一題，廣播給聊天室所有人 |
| 線上名單 | 查看目前在同一個聊天室的人 |
| 跨電腦連線 | 同一個網路的其他電腦可以連進來 |

## 前置需求

- **Docker Desktop**，安裝後要打開，等它顯示 running
- **Python 3**，而且要能使用 Tkinter（圖形介面用的）

確認 Tkinter 可以用：

```bash
python3 -m tkinter
```

跳出一個寫著 Tcl/Tk 的小視窗就代表正常，關掉它即可。沒有跳出視窗的話，先看最下面的「常見問題」。

## 執行步驟

### 1. 啟動伺服器

在專案根目錄執行：

```bash
docker compose up -d --build
docker compose ps
```

要看到 `mysql`、`auth`、`server` 三個容器都在執行。第一次啟動要等 MySQL 初始化，大約半分鐘。

伺服器第一次啟動時會自動建立資料表，並把 100 題辯論題匯入資料庫。

### 2. 開啟聊天室

```bash
python3 client/gui_client.py
```

### 3. 註冊並登入

登入視窗有三個欄位：

| 欄位 | 填什麼 |
|------|------|
| 伺服器位址 | 自己一個人測試填 `localhost`；多台電腦一起用時看下一節 |
| 帳號 | 自己取 |
| 密碼 | 自己取 |

第一次使用按「**註冊**」，註冊成功會直接進入聊天室。之後按「**登入**」。

### 4. 開始聊天

要測試兩個人對話，再開一個終端機視窗執行一次 `python3 client/gui_client.py`，用另一個帳號登入即可。

## 多台電腦一起用

同一個 Wi-Fi 或區域網路底下，其他電腦可以連進來。

**跑伺服器的電腦（A）：**

```bash
ipconfig getifaddr en0        # macOS
ipconfig                      # Windows，看「IPv4 位址」
```

會得到類似 `192.168.1.10` 的數字。

**其他電腦（B）：**

1. 只需要 `client/gui_client.py` 這一個檔案，以及能使用 Tkinter 的 Python。不用安裝 Docker，也不用整個專案。
2. 執行 `python3 gui_client.py`
3. 「伺服器位址」填 A 電腦的 IP

> **重要：所有人填的伺服器位址必須一模一樣。**
> 伺服器是用「client 填的位址」來區分聊天室的。如果 A 填 `localhost`、B 填 `192.168.1.10`，兩個人雖然連到同一台伺服器，卻會被分到不同的聊天室，互相看不到訊息。
> 所以多台電腦一起用時，**A 電腦自己也要填 IP，不要填 `localhost`**。

## 操作說明

| 按鈕 | 作用 |
|------|------|
| 送出 | 送出輸入框裡的訊息。也可以在輸入框連按兩次 Enter |
| 抽辯論題 | 隨機抽一題，聊天室裡所有人都會看到。按過後三秒內不能再按 |
| 線上名單 | 顯示目前在同一個聊天室的帳號 |
| 歷史訊息 | 輸入一個帳號，查詢那個人在這個聊天室說過的所有話 |
| 離開 | 關閉聊天室 |

訊息顯示方式：自己的訊息靠右（綠色），別人的訊息靠左並顯示對方帳號，辯論題置中（黃色）。

## 關閉伺服器

```bash
docker compose down           # 停止，資料保留
docker compose down -v        # 停止並清空資料庫（帳號和訊息都會不見）
```

## 常見問題

| 狀況 | 處理方式 |
|------|------|
| `No module named '_tkinter'` | Python 沒有安裝 Tkinter。Homebrew 的 Python 執行 `brew install python-tk`；或改用 [python.org](https://www.python.org/downloads/) 下載的版本 |
| `macOS 15 (1507) or later required` | 系統版本和 Tk 對不上。更新 macOS，或改用 Homebrew / python.org 的 Python |
| 登入時顯示「無法連線到驗證伺服器」 | 伺服器沒啟動，執行 `docker compose up -d`；或伺服器位址填錯 |
| 其他電腦連不進來 | 檢查防火牆是否擋住 8080 和 8081；學校 Wi-Fi 常會擋裝置互連，可改用手機熱點 |
| 兩個人看不到彼此的訊息 | 兩邊「伺服器位址」填的內容不一樣，詳見上面的「多台電腦一起用」 |
| 抽辯論題顯示「題庫目前沒有題目」 | 題庫沒匯入成功，執行 `docker compose down -v` 再 `docker compose up -d --build` 重建 |

## 專案結構

```text
final_project/
├── auth/                 驗證服務（port 8080）
│   ├── auth.py           註冊、登入
│   └── .env              資料庫連線設定
├── server/               聊天服務（port 8081）
│   ├── server.py         訊息廣播、歷史訊息、抽辯論題
│   ├── topics.py         100 題辯論題庫
│   └── .env              資料庫連線設定
├── client/
│   ├── gui_client.py     圖形化介面（在自己的電腦上執行）
│   └── client.py         終端機版（舊版，仍可使用）
└── docker-compose.yml    三個服務的設定
```

兩種 client 用的是同一套通訊協定，所以圖形版和終端機版可以在同一個聊天室裡互相聊天。

## 技術架構

```text
client（自己的電腦）
   │  TCP socket，一行一則 JSON
   ├──────────────→ auth   :8080   註冊、登入
   └──────────────→ server :8081   聊天、歷史訊息、抽辯論題
                       │
                       └──→ MySQL :3307   帳號、訊息、題庫
```

- **Python 3.11** — 三個程式的開發語言
- **socket（TCP）** — client 與兩個服務之間的連線
- **threading** — 伺服器每個連線一條執行緒；client 用一條執行緒接收訊息
- **JSON** — 訊息格式，一行一則，用 `type` 欄位分辨動作
- **Tkinter** — 圖形化介面
- **MySQL 8.0** — 儲存帳號、訊息與題庫
- **Docker Compose** — 一個指令啟動三個服務
